# Assessing the Impact of AI on the Originality of Final Year Student Projects

## Overview
This project investigates how the use of Artificial Intelligence tools (such as ChatGPT) affects the originality of final-year student projects. It combines survey data with machine learning classification to identify patterns of AI usage and their impact on originality scores.

## Features
- Data cleaning and preprocessing of survey data
- Machine learning model training (Logistic Regression, Random Forest, Decision Tree, SVM)
- Accuracy, precision, recall, and F1-score evaluation
- Visualization of results and feature importance

## Requirements
- Python 3.8+
- Jupyter Notebook
- pandas, numpy, scikit-learn, matplotlib, seaborn, openpyxl

## Installation
```bash
git clone <https://github.com/BIGTUNZ/Assessing-the-Impact-of-AI-on-the-Originality-of-Final-Year-Student-Projects>
cd project_directory
pip install -r requirements.txt
jupyter notebook
```
Open `AI_Originality_Analysis.ipynb` and run all cells in sequence.

## Dataset
The dataset includes survey responses from 157 students, capturing AI usage frequency, CGPA, and originality indicators. Make sure the dataset file (`survey_responses.xlsx` or `ai_originality_data.csv`) is in the same directory as the notebook.

## Usage
1. Load dataset.
2. Run data preprocessing cells.
3. Train models (Logistic Regression, Random Forest, Decision Tree, SVM).
4. Evaluate and visualize results.

## Output
- Classification results showing originality levels.
- Confusion matrices and accuracy metrics.
- Feature importance plots.
